S2G Migrator

S2G Migrator is a personal, single-operator desktop tool that copies files from Microsoft SharePoint Online to a Google shared drive that the operator is a member of.

It runs only on the operator's own Windows computer. It is not offered to the public and has no other users.

The tool uses the Google Drive API to create folders and upload files into the shared drive, and to read back file metadata (size and checksums) to verify each copy.
