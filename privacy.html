S2G Migrator - Privacy Policy

S2G Migrator is a personal desktop tool used only by its operator.

Data accessed

With the operator's consent, S2G Migrator uses the Google Drive API scope https://www.googleapis.com/auth/drive to create folders, upload files, and read file metadata in a Google shared drive the operator is a member of.

Storage and sharing

OAuth tokens and migration records are stored only on the operator's own computer, encrypted with Windows DPAPI. No data is sent to any server other than Google and Microsoft APIs. No data is sold, shared with third parties, or used for advertising or AI model training.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
